# 素材来源与权利边界

参考站：https://linoxa.framer.website/ 。逐文件原始 URL、SHA256 与大小见 `public/templates/linoxa/sources.json`。运行图片、合作品牌图形及视频全部本地托管；素材用于视觉参考，尚未取得照片、品牌、视频及原站内容的商业再分发授权，发布前必须自行取得授权或更换。不得因参考站可访问或代码仓库可见推断这些素材可商业分发。

中文字体采用 MiSans 400/700，来自 misans@4.1.0 原始 Unicode 分片，官方许可：https://hyperos.mi.com/font/ ，许可说明见 `public/templates/linoxa/fonts/misans/LICENSE-SOURCE.md`。MiSans 不是 SIL OFL。英文与数字采用 Poppins 400/600/700，许可见 `public/templates/linoxa/fonts/Poppins-OFL.txt`。未新增字体依赖。

素材完整性核对覆盖原站全部页面 HTML 的图片与经实体解码的 CSS 背景链接、逐页素材映射，以及当前源码中的图片、图形和视频文件名；不能仅以已下载清单作为核对输入。当前来源清单登记 234 个不同运行素材文件（235 条来源记录），已核对文件存在、非空、无 HTML 错误页，并重新计算 SHA256。展示截图源文件保存在 `.tpl/assets/`，与运行素材分别管理。该静态核对不替代页面实际加载、视频播放和动效验收。
