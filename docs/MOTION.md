# 动效观察、实现与验证边界

参考：https://linoxa.framer.website/ 。本文件区分原站已经看到的行为、结构线索与当前源码实现；实现参数来自本工程源码，不冒充原站测量值。应用覆盖 39 页双语路由，并不意味着 39 页所有动画已经逐项或逐帧对照。

## 原站证据边界

内置浏览器可见首页建筑大图、逐字 `LAYOUT`、文字入场结构、建筑模型轮播、视频播放控件、服务列表、横向作品展示及重复滚动文字。两次页面状态中的模型轮播图片不同，页面菜单可实际展开并显示多组页面入口。首页、列表及详情结构也经过页面资料核对。

原站标题的逐字 DOM、重复文本或控件存在只能说明结构与交互线索，不能单独证明特定持续时间、曲线、拖拽回弹或完整循环。没有动态取证的页面或效果仍属未验证。本文件不将本地实现截图、HTTP 200 或源码中的参数当成原站动效一致性证明。

## 三端实现差异

- PC 目标1440×1000：完整横向导航、桌面多组菜单、作品双列或三列瀑布流、文章多列、横向图库和悬浮反馈。
- iPad 目标834×1180：保留合适双列与桌面菜单；部分导航按钮按1100px断点收起；集合页面在1000px以下调整间距和列数。触控不依赖鼠标悬停。
- H5 目标390×844，补测320px：767px以下切换手机菜单与单列主区块，集合页面620px以下重排卡片、作者、元信息与文章目录。视差高度、图片比例、卡片间距与图库宽度随端调整。
- 局部阈值来自当前CSS，未声称与Framer所有断点逐像素相同。系统覆盖式滚动条、触控惯性、视频解码与自动播放差异保留浏览器原生行为。

## 减少动态设置

当前公共组件读取 `useReducedMotion`：关闭视差位移、自动模型轮播、首页02自动切换与模型拖拽，数字立即取终值，标题和区块减少运动，视频不自动播放。CSS在减少动态模式下停止循环动画、压缩过渡并固定标题字符显示；集合卡片关闭悬浮变换。

这不是全站减动实机通过声明。服务切换、菜单退出、FAQ透明度等组件还需要在系统设置开启的真实浏览器中逐项确认；不能只因为存在媒体查询就断言所有非必要运动完全停止。

## 实际验收记录方法

对每项保存触发前、运动中、结束状态；记录语言、页面、端、视口、触发方式和观察到的差异。循环连续观察两轮并测试悬停/焦点/按钮暂停恢复；拖拽检查阈值与释放；视频检查时间推进和暂停；菜单检查Esc、键盘、内部滚动、背景锁定与恢复。最终报告记录真实结果及未执行原因。

尚未确认的完整性项目：39页各区触发顺序与曲线、全站特殊跨页转场、横向图库桌面弹簧拖拽、所有原站视频的各端播放策略、各端全量减少动态覆盖。没有证据时保持未验证，不标记为完整动效1:1通过。
